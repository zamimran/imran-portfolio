# Md Imran — Developer Portfolio

A responsive personal portfolio built with **React + TypeScript + Vite**, styled with **Tailwind CSS v4** and custom CSS, animated with **Framer Motion**, and iconified with **Lucide React**.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Personalize before publishing

Open `src/config.ts` and add your real:
- GitHub profile URL
- LinkedIn profile URL
- LeetCode profile URL
- GitHub repository links for both projects
- Live demo links, if deployed

Links with empty values are hidden automatically. Do not publish guessed or placeholder profile URLs.

## Deploy

Recommended: push this folder to a GitHub repository and import it into **Vercel** or **Netlify**. Use the default Vite build command `npm run build` and output directory `dist`.

## Content accuracy

Portfolio content is based on `Mohammad_Imran_Resume.pdf`. Project summaries and skill names are limited to resume-backed information. Update the content if your resume changes.
